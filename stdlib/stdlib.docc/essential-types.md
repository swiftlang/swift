# Essential Types

Use the most common numeric types, collections, and strings in your code.

## Overview

The Swift standard library contains many useful types such as numeric types with specific bit depths (``UInt8``, ``Float16``) and special purpose collections (``OptionSet``, ``CollectionOfOne``).

That said, nearly all Swift code makes use of a handful of ubiquitous types.
This page collects those types for quick reference, and for simplicity when first learning Swift.
You can also find these types in the main <doc:swift-standard-library> reference.
